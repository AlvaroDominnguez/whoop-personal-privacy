# whoop-personal-privacy
# Política de privacidad — WHOOP Personal

Última actualización: 18 de noviembre de 2026

## 1. Finalidad

Esta aplicación personal utiliza la API oficial de WHOOP para consultar y analizar datos de actividad física, sueño, recuperación y entrenamiento.

Su finalidad es exclusivamente personal: ayudar a comprender y mejorar el rendimiento deportivo.

## 2. Datos tratados

La aplicación puede acceder, con autorización del usuario, a datos como:

- Recuperación y HRV.
- Sueño y sus fases.
- Strain y ciclos de actividad.
- Entrenamientos.
- Datos del perfil y medidas corporales autorizadas.

## 3. Almacenamiento y seguridad

Los datos se procesan y almacenan localmente en el ordenador del usuario.

Las credenciales y tokens de acceso se guardan localmente y no deben publicarse ni compartirse.

## 4. Compartición de datos

Esta aplicación personal no tiene como finalidad compartir, vender ni ceder los datos personales a terceros.

## 5. Revocación del acceso

El usuario puede revocar el acceso de la aplicación desde la configuración de conexiones o aplicaciones autorizadas de WHOOP.

Para consultas relacionadas con esta aplicación, utiliza el contacto del propietario del repositorio de GitHub.
